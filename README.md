# CCNA Static Routing Lab – 3 Routers

Cisco Packet Tracer lab implementing IPv4 static routing across a three-router topology with multiple LANs and serial WAN connections.

## Topology

- 3 Cisco 1941 Routers
- 3 Cisco 2960 Switches
- 3 PCs
- Static Routing Configuration
- IPv4 Subnetting

## Networks

| Network | Usage |
|---|---|
| 172.31.1.0/26 | LAN 1 |
| 172.31.1.128/26 | LAN 3 |
| 172.31.1.192/30 | R1 ↔ R2 Serial Link |
| 172.31.1.196/30 | R2 ↔ R3 Serial Link |

## Skills Practiced

- IPv4 Addressing
- Static Routing
- Router Configuration
- Connectivity Verification
- Basic Troubleshooting
